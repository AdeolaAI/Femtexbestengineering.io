## 🚀 How to Publish This Website on GitHub Pages

Follow this quick YouTube tutorial to enable GitHub Pages and make your site live for free:  

[![Watch the video](https://img.youtube.com/vi/sL9pA2oAewY/0.jpg)](https://www.youtube.com/watch?v=sL9pA2oAewY)

**Steps summary:**
1. Go to **Settings → Pages** in your repository.  
2. Under **Source**, choose **Branch: main** and **Folder: /(root)**.  
3. Click **Save**.  
4. Wait a minute, then your site will be live at  
   👉 `https://yourusername.github.io/`
